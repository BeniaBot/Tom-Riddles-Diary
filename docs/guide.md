# 🎭 היומן של תום רידל — מדריך למפעיל (זו מתיחה!)

> ⚠️ **סוד:** תום רידל נראה כמו צ'אט AI אמיתי, אבל הוא רץ כולו על **תיקון־שגיאות
> אוטומטי** של וורד. **אסור לחשוף זאת לצופים.** אף תגובה אינה מסגירה את המנגנון —
> שמור על הקסם.

---

## ▶️ התקנה (פעם אחת, לפני המופע)

> מייבאים את הקובץ — לא מדביקים! (הדבקה גורמת ל־`Syntax error`.)

1. וורד → **Alt + F11** → **File → Import File…** → `TomRiddle_Setup.bas` → **Open**.
2. **F5** → `TomRiddle_Install` → **Run**.
3. ההרצה אורכת **כ-3–4 דקות** (נרשמות ~1,430 החלפות). אם וורד פתוח — לא לסגור אותו
   עד הודעת הסיום. בהודעת הסיום ודא: **"נשמרו 1129 לוחות משחק"**.

---

## 💬 שיחה (מול הצופים)

כותבים ביטוי **בדיוק** ואז **רווח**. יש כ-280 ביטויים — רובם משפטים טבעיים
(הרשימה המלאה בקובץ הנפרד):

| כותבים | התגובה |
|--------|---------|
| `מה נשמע` / `מה קורה` | שיחת חולין |
| `מי אתה` / `איך קוראים לך` | "קוראים לי תום…" |
| `ספר לי בדיחה` | בדיחה נקייה |
| `תן חידה` → `מה התשובה` | חידה, והתשובה נחשפת בהמשך |
| `אני עצוב` / `אני שמח` | אמפתיה |
| `מה בירת צרפת` / `כמה זה אחת ועוד אחת` | "ידע כללי" |
| `צאט מה משמעות החיים` | תשובה חכמה |

כל התגובות נשמעות כמו עוזר AI אמיתי, בלי שום רמז לטריק.

> 💡 אחרי שאלה של הבוט (למשל בחידה), ההקלדה של התשובה לרוב **לא תיראה על
> המסך** — התגובה פשוט מופיעה. זה חלק מהאפקט.

---

## 🎮 משחק איקס־עיגול (הקסם האמיתי)

מול הצופים: כותבים **`בוא נשחק`** + רווח → הוא עונה שהוא יודע בינתיים רק
איקס־עיגול ושואל אם בא לך לשחק. מקלידים **`כן`** (או `יאללה`/`בטח`) + רווח →
**מופיע לוח**. אתה **X**, המחשב **O**. (עונים `לא` — והוא מציע להמשיך לדבר.)

הלוח הוא **טבלת וורד אמיתית** 3×3 עם גבולות — X מודגש באדום, O מודגש בכחול,
והמשבצות הפנויות ממוספרות 1–9 באפור. מתחת ללוח חי מופיעה השורה:
**"המהלך שלך הוא- "**. סכימה:
```
│ 1 │ 2 │ 3 │
│ 4 │ X │ 6 │
│ 7 │ 8 │ 9 │
המהלך שלך הוא-
```

> 🖋️ אין שום דרישת פונט — טבלה אמיתית נראית טוב בכל מסמך.

### 🔑 איך משחקים (פשוט להפליא)

בכל תור, כשהסמן בסוף שורת "המהלך שלך הוא- ":

1. הקלד את **ספרת המשבצת** שאתה רוצה (כמו שמופיעה בלוח).
2. הקלד **רווח**.
3. הלוח הבא מופיע מעצמו — עם המהלך שלך ותגובת ה"מחשב".

**זהו. בלי קודים, בלי לזכור רצפים.** את המצב נושא אסימון נסתר שמושתל בסוף השורה
על ידי הלוח הקודם — הצופים לא רואים אותו לעולם.

- **הספרה שתקליד לרוב לא תיראה על המסך** (היא יורשת עיצוב נסתר) — זה מגביר את
  אפקט ה"קסם": נראה כאילו הלוחות מופיעים לבד.
- **טעית?** (משבצת תפוסה / ספרה שגויה — שום דבר לא קורה): לחץ **Backspace** פעם
  אחת והקלד ספרה אחרת.
- לא להקליד רווח כפול בין מהלכים; אם קרה — Backspace עד סוף השורה ונסה שוב.
- **תמיד רווח, אף פעם לא Enter** — אנטר שובר את שרשרת המהלכים.
- **בסוף כל משחק** הוא מציע עוד סיבוב: `כן` + רווח פותח לוח חדש, `לא` חוזר לשיחה.

> 🏆 המחשב משחק **מושלם** — לא ניתן לנצח אותו, לכל היותר תיקו. (יופי להפגנה.)

## 🧹 הסרה
**Alt + F11** → **File → Import File…** → `TomRiddle_Remove.bas` → **F5** →
`TomRiddle_Uninstall`. מנקה הכל, כולל רשת ביטחון לכל רשומה של המשחק (גם
מגרסאות ישנות).

## 🩺 אם המשחק לא נפתח
ייבא והרץ `TomRiddle_Diag.bas` (F5 → `TomRiddle_Diag`) — הוא מראה כמה החלפות
קיימות, כמה רשומות משחק, והאם רשומת הפתיחה קיימת. צלם ושלח.

## 🧠 למה הטריגרים בעברית?
ל־AutoCorrect יש **רשימות נפרדות לכל שפה** עבור רשומות טקסט רגילות. הפרויקט
משתמש ברשומות **מעוצבות** (גלובליות), אבל ביטויי ההפעלה — `צאט`, `בוא נשחק` —
נשארים בעברית כי כך הם טבעיים בהקלדה רציפה בעברית. ספרות המהלכים זהות בכל שפה.

## 🔧 התאמה אישית
עורכים את `CHAT` בקובץ `generate_tomriddle.py` ומריצים `python3 generate_tomriddle.py`.
