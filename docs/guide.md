# 🎭 היומן של תום רידל — מדריך למפעיל (זו מתיחה!)

> ⚠️ **סוד:** תום רידל נראה כמו צ'אט AI אמיתי, אבל הוא רץ כולו על **תיקון־שגיאות
> אוטומטי** של וורד. **אסור לחשוף זאת לצופים.** אף תגובה אינה מסגירה את המנגנון —
> שמור על הקסם.

---

## ▶️ התקנה (פעם אחת, לפני המופע)

> מייבאים את הקובץ — לא מדביקים! (הדבקה גורמת ל־`Syntax error`.)

1. וורד → **Alt + F11** → **File → Import File…** → `TomRiddle_Setup.bas` → **Open**.
2. **F5** → `TomRiddle_Install` → **Run**.
3. ההרצה אורכת **כ-2–3 דקות** (נרשמות 1,120 טבלאות). בהודעת הסיום ודא:
   **"נשמרו 1120 לוחות משחק"**.

---

## 💬 שיחה (מול הצופים)

כותבים ביטוי **בדיוק** ואז **רווח**. דוגמאות (הרשימה המלאה בקובץ הנפרד):

| כותבים | התגובה |
|--------|---------|
| `היי צאט` | שלום! נעים מאוד. איך אפשר לעזור? |
| `צאט ספר בדיחה` | בדיחה נקייה |
| `צאט מה משמעות החיים` | תשובה חכמה |
| `צאט אתה בינה מלאכותית` | "כן, אני AI…" |
| `צאט משעמם לי` | מזמין לשחק |

כל התגובות נשמעות כמו עוזר AI אמיתי, בלי שום רמז לטריק.

---

## 🎮 משחק איקס־עיגול (הקסם האמיתי)

מול הצופים: כותבים **`בוא נשחק`** + רווח → **מופיע לוח**. אתה **X**, המחשב **O**.

הלוח הוא **טבלת וורד אמיתית** 3×3 עם גבולות — X מודגש באדום, O מודגש בכחול,
והמשבצות הפנויות ממוספרות 1–9 באפור. מתחת לטבלה שורת סטטוס ("תורך!" וכו').
סכימה (בוורד זו טבלה מעוצבת, לא טקסט):
```
│ 1 │ 2 │ 3 │
│ 4 │ X │ 6 │
│ 7 │ 8 │ 9 │
תורך!  :)
```

> 🖋️ אין שום דרישת פונט — טבלה אמיתית נראית טוב בכל מסמך.

### 🔑 הקלט הסודי שלך (הצופים לא אמורים להבין)
וורד לא זוכר מהלכים — לכן הקוד שאתה מקליד **מכיל את כל רצף המהלכים שלך**:

מקלידים `תתת` + רצף הספרות של המשבצות שבחרת עד עכשיו + רווח.

| המהלך שלך | מה מקלידים |
|-----------|-------------|
| ראשון, משבצת 5 | `תתת5` |
| אחר כך משבצת 9 | `תתת59` |
| אחר כך משבצת 3 | `תתת593` |

הקוד גדל בספרה בכל מהלך. הצופים רואים רק את **הלוח מתעדכן** ואת "תורך!" / "ניצחתי!".

> 🎩 **טיפ למתיחה:** הקלד את הקוד מהר, או הסתר את המסך לרגע, כדי שלא יבחינו ב־`תתת`.
> 🏆 המחשב משחק **מושלם** — לא ניתן לנצח אותו, לכל היותר תיקו. (יופי להפגנה.)

## 🧹 הסרה
**Alt + F11** → **File → Import File…** → `TomRiddle_Remove.bas` → **F5** →
`TomRiddle_Uninstall`. מנקה הכל, כולל רשת ביטחון לכל רשומה של המשחק.

## 🩺 אם המשחק לא נפתח
ייבא והרץ `TomRiddle_Diag.bas` (F5 → `TomRiddle_Diag`) — הוא מראה כמה החלפות
קיימות ואת ערך רשומת המשחק. צלם ושלח.

## 🧠 למה טריגר בעברית ולא "ttt"?
ל־AutoCorrect יש **רשימות נפרדות לכל שפה**. טקסט לטיני נבדק מול הרשימה האנגלית,
וטקסט עברי מול העברית. מכיוון שהכול מותקן ברשימה העברית, טריגר עברי (`תתת`) הוא
זה שנורה — בדיוק כמו תגובות השיחה.

## 🔧 התאמה אישית
עורכים את `CHAT` בקובץ `generate_tomriddle.py` ומריצים `python3 generate_tomriddle.py`.
